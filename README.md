# Financial Transaction Risk & Anomaly Intelligence System

An end-to-end data analytics and machine learning project for identifying
suspicious financial transactions, detecting behavioral anomalies,
estimating fraud risk, and presenting actionable insights through Power BI.

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- MySQL
- SQLAlchemy
- Power BI
- DAX
- SHAP
